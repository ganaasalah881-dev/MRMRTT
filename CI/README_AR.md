1. على Ubuntu: اختبارات حراس السياسات Python، وفحص `double` وXAML وRTL وأسماء عناصر XAML.

3. اختبارات قبول الخدمات والطاقة والتدقيق.
4. أدوات WPF الفعلية للاستلام والتخطيط/الطاقة وأوامر اليوم والتسجيل الفعلي والطباعة.
5. عند نجاح فحوصات السياسات والاختبارات فقط: نشر `win-x64` self-contained، ثم تثبيت الحزمة وتشغيلها أول مرة على Windows runner نظيف، والتحقق من إنشاء قاعدة SQLite وملف الإعداد والاختصار، واختبار إزالة البرنامج مع إبقاء البيانات.
