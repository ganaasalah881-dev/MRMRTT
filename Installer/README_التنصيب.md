# بناء وتنصيب MfgSystem — الإصدار 1.50.74

## أدوات الحزمة

| الملف | الوظيفة |
|---|---|
| `1-بناء_الحزمة.bat` | على Windows: يستعيد الحل، يبنيه Release، يشغّل جميع مشروعات الاختبار، ثم ينشر نسخة win-x64 مستقلة ويجهز ZIP. |
| `2-تنصيب.bat` | يتحقق من رقم الإصدار وSHA-256، يثبت ملفات هذا الإصدار فقط وينشئ اختصاراته. |
| `تشغيل_1.50.74.bat` | مشغّل إصدار واضح؛ يرفض العمل إن لم يطابق `VERSION.txt` النسخة 1.50.74. |
| `فحص_المتطلبات.bat` | يفحص Windows والمعمارية والمساحة وبعض المتطلبات الاختيارية. |
| `إلغاء_التنصيب.bat` | يزيل ملفات البرنامج والاختصارات الخاصة بالإصدار 1.50.74؛ يبقي بياناته افتراضياً. |

## بناء حزمة Production من المصدر

يتطلب البناء Windows x64 و.NET 8 SDK وPython 3 مع مشغّل `py` لاجتياز فحوصات السياسات قبل بناء الحزمة. من جذر المستودع شغّل:

```bat
Installer\1-بناء_الحزمة.bat
```

ينفذ السكربت بالترتيب:

1. `dotnet restore DateERP.sln`
2. `dotnet build DateERP.sln -c Release -warnaserror`
3. تشغيل مجموعة xUnit كاملة من `tests/DatesErp.Tests`.
4. تشغيل قبول دورة العمل والطاقة وتدقيق الوحدات، ثم أدوات WPF الفعلية للاستلام والتخطيط/الطاقة وأوامر اليوم والتسجيل الفعلي والطباعة.
5. استعادة runtime الخاص بـ`win-x64` ونشر تطبيق WPF بوضع self-contained.
6. إنشاء `VERSION.txt` و`SHA256.txt` وإضافة المثبّت والمشغّل ثم ضغط الحزمة.

لا ينتج إصدار الحزمة إلا إذا نجحت الخطوات السابقة. المساران المقصودان هما:

```text
artifacts\MfgSystem_1.50.74_win-x64\
artifacts\MfgSystem_1.50.74_win-x64.zip
```

الحزمة self-contained ولا تتطلب تثبيت .NET Runtime على الجهاز المستهدف. يلزم تشغيل البناء والنشر الفعليين على Windows؛ لا يكفي فحص الملفات نصياً لإثبات صلاحية الحزمة.

## التثبيت على جهاز نظيف

1. انقل مجلد `MfgSystem_1.50.74_win-x64` أو استخرج ملف ZIP كاملاً إلى مجلد محلي.
2. اختياري: شغّل `فحص_المتطلبات.bat`.
3. شغّل `2-تنصيب.bat`. يرفض المثبّت الملفات الناقصة أو الإصدار المخالف أو SHA-256 غير المطابق.
4. عند التشغيل بصلاحيات مسؤول يكون مجلد البرنامج `%ProgramFiles%\MfgSystem\1.50.74`؛ وإلا يستخدم `%LocalAppData%\Programs\MfgSystem\1.50.74`.
5. شغّل الاختصار **MfgSystem 1.50.74** أو `تشغيل_1.50.74.bat` من مجلد التثبيت. المشغّل يتحقق من هوية النسخة قبل تشغيل `MfgSystem.exe`.

لأتمتة التثبيت في اختبارات معزولة يمكن تمرير `/NO-LAUNCH /NO-PAUSE`، وتحديد مجلد مؤقت عبر متغير البيئة `MFGSYSTEM_INSTALL_DIR`. لا تستخدم مسار مجلد بيانات التطبيق كتجاوز لمجلد البرنامج.

## إعدادات وبيانات هذا الإصدار

جميع بيانات المستخدم لهذا الإصدار تحفظ في:

```text
%LOCALAPPDATA%\MfgSystem\1.50.74\
```

ومنها `config.json` وقاعدة SQLite المحلية `mfgsystem_local.db` ومجلد `logs`. ينشئ التطبيق مجلده وقاعدته عند أول تشغيل، ولا يقرأ إعدادات أو قاعدة قديمة ولا يرحّلها تلقائياً. لا يعتمد المثبّت أو المشغّل على مخرجات نشر أو مسارات تثبيت من إصدار سابق.

يبدأ الإعداد الجديد بالوضع المحلي. يمكن للمسؤول ضبط SQL Server من داخل النظام عند الحاجة؛ يظل إعداد الاتصال محفوظاً في مجلد الإصدار أعلاه. النسخ الاحتياطية لها مجلد منفصل قابل للتغيير من إعداد النسخ الاحتياطي؛ وعند استخدام SQL Server يجب أن يكون المسار متاحاً لحساب خدمة SQL Server.

## إزالة البرنامج

شغّل `إلغاء_التنصيب.bat` من الحزمة/مجلد التثبيت. يزيل ملفات مجلد برنامج `1.50.74` واختصارات هذا الإصدار فقط. الخيار الافتراضي يحتفظ بـ`%LOCALAPPDATA%\MfgSystem\1.50.74`؛ لا تحذف بيانات المستخدم إلا باختيار الحذف صراحةً. شغّل الإزالة تحت حساب Windows الذي يملك بيانات المستخدم إذا أردت حذفها.

> هذه الأدوات مهيأة للإصدار 1.50.74 فقط. يجب إجراء build وtest والتشغيل الفعلي على Windows قبل اعتبار أي حزمة جاهزة للإنتاج.
