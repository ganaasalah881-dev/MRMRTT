# CI — مصدر واحد وفحوص قابلة لإعادة التنفيذ

ملف التشغيل: `.github/workflows/ci.yml`، وليس نسخة في هذا المجلد.

- بناء Release كامل على Windows وLinux مع `-warnaserror`؛ لا نعيد بناءً تزايدياً لعدّ التحذيرات.
- اختبار xUnit وتشغيل AcceptanceRunner وUnitRuleAudit في **نفس وظيفة البناء**.
- NuGet audit لجميع الاعتماديات، بما فيها المتعدية؛ تنبيهات الثغرات أو فشل تحميل مصدرها تُفشل الاستعادة عبر Directory.Build.props.
- حارس Python يحذف التعليقات والنصوص قبل البحث عن المعالجات الفارغة، ويُختبر بحالات سلبية وإيجابية.
- التحقق من RTL على جذر XML لا بمجرد ظهور النص في تعليق.
- لا تحويل تلقائياً لأعمدة double القائمة: `legacy-double-members.json` يسجل الأسماء الحالية (105، منها خصائص محسوبة). هذا قيد توافق معلن مع المخطط الحالي، وليس ادعاءً بإزالة الدين التقني. لا يُسمح بعضو جديد حتى لو حُذف عضو قديم وأبقي العدد نفسه. أي إضافة إلى القائمة تستلزم مراجعة صريحة؛ لا تُحدّث القائمة تلقائياً في CI.

```bash
python -m unittest discover -s tools/ci -p 'test_*.py'
python tools/ci/structural_checks.py
```

يحتاج تشغيل واجهة WPF واختبار الطباعة/SQL Server الحقيقي بيئة Windows مناسبة؛ نجاح البناء المتقاطع وحده لا يكفي.
