# 🛫 قائمة إقلاع تاريخية — تشغيل MfgSystem لأول مرة بـ10 مستخدمين

**الإصدار الذي أُعدّت له القائمة:** 1.50.60 — **التاريخ:** 13/09/2026

> هذه القائمة تاريخية وليست إثبات قبول أو دليل تشغيل خاصاً بـ1.50.74. للحزمة الحالية استخدم `Installer/README_التنصيب.md` و`Documentation/Installation_Guide.md`، ونفّذ فحص Windows الفعلي قبل الإنتاج.
**الاستخدام:** اطبع هذه القائمة وعلّقها بجانب جهاز الخادم. اشطب كل بند ✓ بالترتيب — لا تنتقل لبند قبل إتمام ما قبله. مثل قائمة إقلاع الطيار: لا إقلاع بذاكرة، بل بقائمة.

> ⏱ الزمن التقديري الكامل: يوم عمل واحد (المرحلة أ+ب+ج) ثم يوم تشغيل أول (د) وأسبوع مراقبة (هـ).

## المرحلة (أ) — الخادم وقاعدة البيانات ⚙️

| ✓ | البند | خطوات النقر | كيف تتأكد أنه تم؟ |
|---|---|---|---|
| ☐ | A1. تثبيت SQL Server على جهاز الخادم | شغّل `SQLEXPR_x64_ENU.exe` ← اختر **Basic** ← وافق على الترخيص ← Install ← عند النهاية اضغط **Install SSMS** (أو شغّل ملف SSMS 20.2.1 منفصلاً) | تظهر أيقونة SSMS في قائمة ابدأ |
| ☐ | A2. تفعيل اتصال الشبكة للخادم | افتح **SQL Server Configuration Manager** ← SQL Server Network Configuration ← Protocols ← انقر يمين **TCP/IP** ← Enable ← أعد تشغيل خدمة SQL Server (كليك يمين ← Restart) | الحالة Running بعد Restart |
| ☐ | A3. إنشاء قاعدة النظام | افتح SSMS ← اتصل بـ `localhost` (Windows Authentication) ← كليك يمين Databases ← **New Database** ← الاسم حسب دليل `Server_Setup.md` | القاعدة ظاهرة في Object Explorer |
| ☐ | A4. مجلد النظام على الخادم | انسخ محتوى حزمة **FULL** إلى `D:\MfgSystem` على الخادم | المجلد موجود وبداخله ملفات البرنامج |
| ☐ | A5. البناء الأول | شغّل `update.bat` من مجلد النظام ← انتظر تقرير **BUILD SUCCESS** ثم **COPY SUCCESS** | الرسالة الخضراء/النص `[SUCCESS]` في آخر النافذة |
| ☐ | A6. فحص الاتصال من البرنامج | افتح النظام من الخادم ← شاشة إعداد الاتصال ← **فحص الاتصال** | الخطوات الخمس كلها ✓ (الخادم/الخدمة/القاعدة/الدخول/الاتصال) |

**⛔ توقف هنا إن فشل أي بند — لا تكمل والقاعدة غير موصولة.**

## المرحلة (ب) — الاختبارات الآلية والفحص الذاتي 🧪

| ✓ | البند | خطوات النقر | كيف تتأكد؟ |
|---|---|---|---|
| ☐ | B1. تشغيل حزمة الاختبارات الكاملة | شغّل `فحص_التقارير_تشغيل_الاختبارات.bat all` | السطر الأخير `[SUCCESS] All executed audit tests passed` — **الصورة الكاملة (~800 اختبار)** |
| ☐ | B2. اختبارات مسارات التصحيح الجديدة | نفس الملف بالحجة `corr` | `[SUCCESS]` |
| ☐ | B3. الفحص الذاتي من داخل النظام | افتح النظام ← شاشة **«معلومات النظام»** ← زر **الفحص الذاتي** | الخلاصة «✅ لا خلل بنيوي» — والأقسام الستة: الاتصال/الأولية/التشغيلي/الاتساق/**الفحص العميق**/الشاشات |
| ☐ | B4. حفظ تقرير الفحص | الملف يُكتب تلقائياً في `%LOCALAPPDATA%\MfgSystem\1.50.74\logs\selftest.txt` — انسخه لمجلد النظام كأرشيف اليوم الأول | الملف موجود وتاريخه اليوم |
| ☐ | B5. فحص مطابقة المخزون | شاشة «معلومات النظام» ← زر **فحص مطابقة المخزون** | «لا فروق» (طبيعي قبل أي إدخال) |

> **ملاحظة:** الفحص الذاتي يعمل **تلقائياً عند كل إقلاع** بلا نوافذ، والفحص العميق (الجديد) يكشف آلياً: فرق الأرصدة عن دفتر الحركات، القيود المكررة، رايات الاعتماد المتناقضة، السلاسل الممزقة (مستند حي على دفعة ملغاة)، الحسابات بلا مدير فعّال، ونقص صفوف مصفوفة الصلاحيات.

| ☐ | C4. العمليات الحساسة — **للخارج عن الدور فقط** | شاشة **الصلاحيات والأدوار** ← الدور الموثوق ← المورد «الاستلام» ← فعّل «تصحيح السلسلة» و«تصحيح كمية/عميل مستند معتمد» لمن تثق به **فقط** (افتراضياً: المدير وحده) | الموظف العادي **لا يرى** زرّي 🛠 و🔗 في الاستلام — جرّب بحساب مخازن عادي وتأكد بعينك |

1. **شغّل الفحص الذاتي** (معلومات النظام ← فحص ذاتي) — هو يجيب سؤال «هل العطل من جهازي أم من البرنامج؟».
2. **انسخ الملف** `%LOCALAPPDATA%\MfgSystem\1.50.74\logs\selftest.txt`.
3. أرسل الملف + اسم الشاشة + رقم المستند + لقطة الخطأ كما هي.
