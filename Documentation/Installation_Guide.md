# دليل التثبيت والتشغيل — MfgSystem 1.50.74

## المتطلبات

- Windows 10/11 على جهاز x64.
- حزمة النشر self-contained لا تتطلب تثبيت .NET Runtime على جهاز المستخدم.
- عند البناء من المصدر يلزم Windows و.NET 8 SDK؛ راجع `Installer/README_التنصيب.md`.
- لا يلزم SQL Server للتشغيل المحلي بـSQLite. عند استخدام قاعدة مركزية، يلزم إعداد SQL Server والشبكة وحسابات الوصول بشكل مستقل.

## إنشاء الحزمة

من جذر شجرة المصدر على Windows:

```bat
Installer\1-بناء_الحزمة.bat
```

السكربت ينفذ restore ثم Release build للحل `DateERP.sln`، ويشغّل الاختبارات، ثم ينشر `win-x64` ويولّد الإصدار والـSHA-256. لا تعتمد على أي مجلد نشر سابق. المخرجات:

```text
artifacts\MfgSystem_1.50.74_win-x64\
artifacts\MfgSystem_1.50.74_win-x64.zip
```

لا توزّع الحزمة قبل نجاح البناء والاختبارات على Windows ومراجعة سجل CI.

## التثبيت على جهاز المستخدم

1. انقل مجلد النشر كاملاً أو استخرج ZIP كاملاً إلى مجلد محلي.
2. شغّل `2-تنصيب.bat`؛ يتحقق من `VERSION.txt` ومن SHA-256 للملف التنفيذي قبل النسخ.
3. مع صلاحية مسؤول يكون مجلد التطبيق `%ProgramFiles%\MfgSystem\1.50.74`؛ وإلا يكون `%LocalAppData%\Programs\MfgSystem\1.50.74`.
4. استخدم الاختصار `MfgSystem 1.50.74` أو المشغّل `تشغيل_1.50.74.bat`، الذي يرفض تشغيل حزمة غير مطابقة للإصدار.

## إعدادات الاتصال وقاعدة البيانات المحلية

كل إعدادات وبيانات المستخدم المحلية محفوظة في مساحة هذا الإصدار:

```text
%LOCALAPPDATA%\MfgSystem\1.50.74\
```

ملف إعداد الاتصال: `config.json`؛ قاعدة SQLite المحلية: `mfgsystem_local.db`؛ والسجلات في `logs`. ينشئ التطبيق إعداداً وقاعدة جديدين عند أول تشغيل. لا يقرأ ولا يهاجر `config.json` أو قواعد بيانات من تثبيتات سابقة تلقائياً، ولا يعتمد على مخرجات نشر أو مسارات تثبيت من إصدار سابق.

يبدأ التشغيل النظيف بالوضع المحلي. إذا كانت المؤسسة تستخدم SQL Server مركزياً، يضبط المسؤول اتصال هذا الإصدار من شاشة إعداد الاتصال، ويتحقق من صحة الاتصال وصلاحيات الحساب قبل إدخال بيانات تشغيلية. لا تستخدم قاعدة الإنتاج للتحقق الأولي من نسخة جديدة؛ جهّز قاعدة اختبار منفصلة ونسخة احتياطية قابلة للاستعادة.

## النسخ الاحتياطي

تُخزن النسخ في مجلد مستقل باسم الإصدار، قابل للتغيير من إعداد النسخ الاحتياطي. مع SQL Server يجب أن يكون المسار مرئياً وقابلاً للكتابة لحساب خدمة SQL Server نفسه، وليس لحساب سطح المكتب فقط. اختبر الاستعادة على قاعدة منفصلة قبل الاعتماد.

## الإزالة

شغّل `إلغاء_التنصيب.bat`. يحذف ملفات برنامج الإصدار 1.50.74 واختصاراته فقط، ويُبقي بيانات `%LOCALAPPDATA%\MfgSystem\1.50.74` افتراضياً. حذف البيانات اختيار صريح، ويجب تنفيذه تحت حساب Windows نفسه الذي يملكها.

## قبول جهاز نظيف

قبل النشر العام، تحقّق على Windows نظيف من: اكتمال التثبيت، هوية الإصدار، إنشاء `config.json` وقاعدة SQLite ومخططها في المسار الجديد، ظهور السجلات، عمل الاتصال المركزي إن كان مستخدماً، ودورة العمل الكاملة على قاعدة اختبار. نجاح build أو الاختبارات البنيوية وحده لا يثبت هذه الخطوات اليدوية.
