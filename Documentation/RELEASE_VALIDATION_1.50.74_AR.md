# قائمة تحقق اعتماد MRMRTT 1.50.74 على Windows

## الحالة

**غير مكتمل في بيئة التطوير الحالية.** هذه القائمة لا تثبت نجاح build أو تشغيل WPF أو المثبّت. يجب تسجيل نتيجة كل بند على جهاز Windows؛ لا تُرقَّ قاعدة الإنتاج لاختبار الإصدار.

## 1. البناء والاختبارات

- [ ] على Windows مع .NET 8 SDK: `dotnet restore DateERP.sln`.
- [ ] `dotnet build DateERP.sln -c Release` ينجح.
- [ ] `dotnet test tests\DatesErp.Tests\DatesErp.Tests.csproj -c Release` ينجح.
- [ ] `AcceptanceRunner`, `PlanningAcceptance`, `UnitRuleAudit` وWPF smoke suites تنجح عبر `Installer\1-بناء_الحزمة.bat` أو CI.
- [ ] فحوصات Python/XAML كلها PASS ولا تظهر هوية جديدة من نوع `double` أو ألوان hex مضمّنة.
- [ ] الاحتفاظ بروابط CI والسجلات وSHA-256 للحزمة.

## 2. جهاز نظيف وتثبيت النسخة

- [ ] استخدم Windows 10/11 x64 نظيفاً أو حساب Windows اختبار جديداً، دون قاعدة أو إعداد MfgSystem سابقة.
- [ ] انقل `artifacts\MfgSystem_1.50.74_win-x64.zip` كاملاً، واستخرجه محلياً.
- [ ] شغّل `2-تنصيب.bat`؛ يجب أن يرفض نسخة غير مطابقة أو hash خاطئ، وينشئ اختصار `MfgSystem 1.50.74`.
- [ ] تحقق من أن الاختصار يشير إلى `تشغيل_1.50.74.bat` وأن المشغّل يرفض `VERSION.txt` المفقود/المختلف.
- [ ] تأكد أن بيانات هذا الإصدار تنشأ فقط تحت `%LOCALAPPDATA%\MfgSystem\1.50.74`، بما فيها `config.json` و`mfgsystem_local.db` و`logs`.
- [ ] شغّل التطبيق وتحقق من نجاح إنشاء مخطط SQLite والإعداد المحلي، ثم أعد التشغيل وتأكد من فتح القاعدة نفسها.
- [ ] تأكد أن إصدار النافذة والتقارير المطبوعة يعرضان 1.50.74. تحقق أن التثبيت لا يقرأ أو يغيّر مجلدات/إعدادات أي إصدار آخر.

## 3. اختبار دورة العمل بقاعدة اختبار معزولة

نفّذ دورة اختبار موثقة بحسابات اختبار وصلاحياتها المناسبة، دون تغيير قواعد العمل الحالية:

- [ ] الاستلام: مسودة وحفظ/إعادة فتح، اعتماد، منع التكرار، والتحقق من الدفعة والرصيد والتتبع.
- [ ] التخطيط والطاقة: إدخال خطة ضمن الطاقة وخطة تتجاوزها، التواريخ والوردية والخط، الحفظ وإعادة الفتح؛ وثّق نتائج التحقق كما هي في قواعد الإصدار.
- [ ] أمر الإنتاج: إنشاؤه من الخطة المعتمدة والتحقق من ثبات العميل والصنف والكمية والمراجع.
- [ ] تشغيل الوردية والتنفيذ: بدء/استئناف/إغلاق التشغيل وتسجيل المنتج الفعلي دون تجاوز الحراس القائمة.
- [ ] الجودة: تسجيل المقبول والمرفوض واعتماد الفحص والتحقق من انتقال الكميات الصحيحة فقط.
- [ ] المخزون والتسليم: استلام التام، تحقق أرصدة العميل/الصنف/الدفعة/العبوة، تنفيذ تسليم جزئي، ومنع التسليم فوق المتاح أو لعميل آخر.
- [ ] التتبع والتدقيق: افتح مستندات المصدر والوجهة وتأكد من بقاء الروابط وسجل المستخدم/التاريخ بعد كل مرحلة.
- [ ] اطبع المستندات والتقارير وراجع المحتوى واتجاه الصفحة والصفحات وPDF.

## 4. الإزالة وإعادة التثبيت

- [ ] شغّل `إلغاء_التنصيب.bat`: تزال ملفات البرنامج واختصارات 1.50.74 فقط، وتبقى البيانات عند الخيار الافتراضي.
- [ ] أعد التثبيت وتأكد من بقاء قاعدة 1.50.74 سليمة.
- [ ] على نسخة اختبار منفصلة فقط، جرّب حذف البيانات صراحةً وتأكد من عدم مساس أي إصدار آخر.
