# دليل المستخدم — Date ERP

## التشغيل اليومي
```
نقرة مزدوجة على "Date ERP" ← تسجيل الدخول ← لوحة التحكم
```
- **اسم المستخدم/كلمة المرور** من مسؤول النظام. عند أول دخول سيجبرك النظام على تغيير كلمة المرور.
- **تذكرني**: يحفظ اسم المستخدم فقط (لا كلمة المرور).

## سير العمل الكامل (§7)
```
استلام التمور ← دفعة (Lot) ← اعتماد ← خطة إنتاج ← أمر إنتاج
← حساب المواد ← صرف المواد ← تنفيذ الإنتاج ← فحص الجودة
← إغلاق الأمر ← استلام الإنتاج التام ← مخزن التام ← تسليم العميل
```
النظام يمنع تجاوز أي مرحلة: لا تسليم قبل فحص معتمد، لا تنفيذ لأمر غير معتمد، لا إغلاق لأمر ناقص.

## الشاشات الرئيسية
| الشاشة | الوظيفة الأساسية |
|---|---|
| لوحة التحكم | مؤشرات عامة + أحدث العمليات |
| استلام التمور | حفظ البنود ثم اعتماد ينشئ الدفعات ويقيد الوارد |
| خطة الإنتاج | اختيار الدفعات المتاحة (تُخصم كل الخطط النشطة تلقائياً) |
| أوامر الإنتاج | الاعتماد يخصم الخام ويصرف المواد فوراً |
| صرف المواد | صرف/تسجيل استهلاك وهالك/إرجاع فائض |
| فحص الجودة | نتائج + أصناف ثانوية (حشف/نوى) بالكيلو |
| استلام الإنتاج التام | إصدار للمخزن ثم سند استلام كلي/جزئي |
| تسليم العملاء | من رصيد العميل فقط — لا تسليم لعميل آخر |
| مركز التقارير | 15 تقريراً: معاينة، طباعة، PDF، Excel |
| النسخ الاحتياطي | نسخة كاملة + تحقق + استعادة (إداري) |

## أزرار النماذج (§23)
`جديد | حفظ | تعديل | حذف | تراجع | طباعة | إغلاق`
- زر **تراجع** يمسح البيانات غير المحفوظة ويعيد النموذج جديداً — **لا يحذف أي سجل محفوظ**.

## رسائل قد تراها
| الرسالة | المعنى | الإجراء |
|---|---|---|
| تم تعديل هذا السجل بواسطة مستخدم آخر | مستخدم آخر حفظ قبلك (§5) | أعد تحميل الشاشة |
| تعذر الاتصال بالخادم. لم يتم حفظ العملية | انقطعت الشبكة أثناء الحفظ (§21) | أعد المحاولة بعد عودة الشبكة |
| الكمية أكبر من المتوفر | محاولة صرف فوق الرصيد (§8) | راجع الرصيد في شاشة الأرصدة |
| حدث خطأ أثناء تنفيذ العملية | خطأ مسجل | أبلغ مسؤول النظام وارجع `%LOCALAPPDATA%\MfgSystem\1.50.74\logs` |

## التقارير (§25)
مركز التقارير → اختر التقرير → (اختيارياً من/إلى تاريخ) → **تشغيل**:
- معاينة فورية داخل الشاشة
- **طباعة**: نافذة الطباعة الأصلية لويندوز (تشمل معاينة الطباعة)
- **تصدير PDF** و**تصدير Excel** مباشرة — دون متصفح

## انقطاع الشبكة (§21)
- أي عملية حساسة أثناء الانقطاع: **تُلغى بالكامل (Rollback)** — لا حفظ جزئي.
- عند عودة الشبكة استمر بالعمل بشكل طبيعي.
